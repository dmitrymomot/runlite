Quick Start Guide

1. Install Runlite CLI

If you haven't already, install the runlite command-line tool:

runlite --version

2. Add a Domain

Register a domain for your application:

runlite domain add yourdomain.com

3. Deploy Your App

Deploy your Go application:

runlite app create myapp
runlite deploy

4. View Logs

Monitor your application:

runlite logs myapp
